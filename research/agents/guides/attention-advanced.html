01 · 从翻译任务理解 Transformer

题名：注意力就是你所需要的。Vaswani 等提出 Transformer。这里的标题强调用注意力替代序列对齐的循环/卷积主干；实际网络仍有前馈网络、嵌入、归一化等组件。

先想一个翻译系统：读懂源句，再根据源句和已经翻译出的部分，预测下一个目标 token。本页的人为切词只是教学示意。

02 · 顺序计算与并行计算

同一层自注意力：

×

注意力允许同一层的多个位置一起做矩阵运算，远处两个位置也能直接建立联系。代价是全局注意力要形成 n×n 的比较关系。

训练时目标序列已知，可以遮住未来后并行计算多个位置的预测；推理时未来输出未知，通常仍要自回归逐 token 生成。并行训练不代表能一次生成任意长度回答。

04 · Q、K、V 分别在做什么

符号直观问题来源
Q · Query这个位置要找什么线索？XW_Q
K · Key每个位置用什么特征被匹配？XW_K
V · Value匹配之后取走什么信息？XW_V

Q、K、V 是学习到的向量变换。“提问、标签、内容”是帮助理解的比喻，不是人为给每个词贴好的语义标签。同一个 token 能同时提供 Q、K、V。

QKᵀ → 除以 √d_k → 加遮罩 → 按行 softmax → 乘 V

softmax 把一行分数变成和为 1 的非负权重。V 的加权和得到新的表示，不是直接输出“下一个词”；后面还需要其他层与词表输出投影。

05 · 真正算一次注意力

点选查询位置，切换投影或遮罩。这里 token 是“我 / 爱 / 你 / 。”，每个位置的人造二维向量都可见。两组投影模拟不同 head；数值没有来自训练模型。

矩阵行＝查询位置，列＝被读取位置；深色表示权重大，× 表示遮住。

练习：选“爱”，打开因果遮罩。“你”和“。”的权重应变成 0；已知输入不变时，关闭遮罩再观察它们如何参与分配。

缩放是为了控制点积随维度增长带来的数值幅度，缓解 softmax 过度尖锐。这只有二维，变化较温和；不能用这个小例子的效果大小推断真实高维模型的训练稳定性。

06 · 多头：不同投影后再合并

多个 head 使用不同的 Q/K/V 投影，同时生成不同表示，拼接后再做一次线性变换。不是把同一组权重复制很多份，也不保证每个头都能解释成固定的“语法头”或“指代头”。

同一层输入 X
→
头 1：投影 → Attention
头 2：投影 → Attention
…
→
Concat 拼接
→
W_O 输出投影
head_i = Attention(XW_Qᵢ, XW_Kᵢ, XW_Vᵢ)
MultiHead = Concat(head₁,…,head_h)W_O

07 · 三种注意力放在哪里

类型Q 来自K、V 来自可读位置
编码器自注意力源句表示同一源句表示全部非 padding 的源位置
解码器遮罩自注意力已知目标前缀同一目标前缀当前位置及之前
编码器—解码器注意力解码器表示编码器最终输出全部非 padding 的源位置

“self” 指 Q 与 K/V 来自同一条表示序列；cross-attention 则跨两条序列。因果遮罩限制未来，padding mask 排除补齐位置，两者用途不同。

注意目标输入右移：输入“起始符、我、爱”，分别预测“我、爱、你”。每个位置能看见当前位置的输入 token，但看不到自己要预测的答案。

原论文：LayerNorm(x + Sublayer(x))
FFN(x) = ReLU(xW₁+b₁)W₂+b₂

残差保留输入并叠加变化；LayerNorm 对单个位置的特征维度进行归一化；FFN 对各位置单独变换，参数跨位置共享。基础配置 FFN 为 512 → 2048 → 512。

这是原论文的编码器—解码器及 post-norm 结构。不要把它与所有现代 decoder-only 模型、pre-norm、RoPE 或其他激活函数混为一谈；这些是后续设计选择。

09 · 形状与代码：防止“公式看懂，维度错了”

计算形状（省略 batch、单头）
Xn × d_model
Q、Kn × d_k
QKᵀ 与 An × n
Vn × d_v
AVn × d_v
# 教学伪代码；softmax 必须按键所在维度归一化
Q, K, V = X @ Wq, X @ Wk, X @ Wv
scores = Q @ K.T / sqrt(d_k)
scores = where(allowed, scores, -inf)
scores = scores - scores.max(axis=-1, keepdims=True)
exp_scores = exp(scores)
A = exp_scores / exp_scores.sum(axis=-1, keepdims=True)
O = A @ V

每个查询至少需要一个允许访问的位置，否则全是 −∞ 的行会使这个简单实现产生 NaN。交叉注意力时，源长度 m 与目标长度 n 不同，分数矩阵是 n×m；不能硬套 n×n。

如果 A 的一行和不为 1，优先检查什么？

检查 softmax 轴是否沿着键位置、是否在 softmax 之前加 mask、有没有整行被遮住、数值是否溢出。不要对整个矩阵只做一次归一化。

为什么 QKᵀ 后还要乘 V？

QKᵀ 只给出匹配分数；softmax 得到权重。乘 V 才把各位置的内容按权重混合，形成当前查询的新表示。

推理时能像训练时一样一次预测整句话吗？

标准自回归生成需要前面输出作为后面输入，通常逐 token 推进。训练目标已知，右移输入并遮住未来，可并行计算各位置的损失。

注意力权重大，能否证明这个词是答案的唯一原因？

不能。后续层、其他头、残差与 FFN 都会改变结果。权重可用于观察，不能单独当成完整的因果解释。

缓存 K/V 会改变注意力的定义吗？

在相同输入和相容实现条件下，缓存是在自回归过程中复用过去位置的 K/V，避免重复计算；它不意味着模型不再需要读取这些历史状态。KV cache 是与 lecture-03 的连接，不是本文所有实现细节的逐项复现。

可以交付的一次小练习

  1. 不用框架写出单头 attention，打印每一步矩阵形状。
  2. 验证每行权重和为 1、未来位置权重为 0。
  3. 改变一个未来 token 的 V，验证因果遮罩下更早位置输出不变。
  4. 再加入多头拼接与输出投影，并画出数据流。
